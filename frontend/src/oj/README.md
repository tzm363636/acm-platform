# 在线评测模块

本模块沿用 Vue 3 / TypeScript / Vite 和现有导航。入口为 `oj.html`，使用独立的 Vue Router hash 路由，支持静态部署，不改首页路由或其他页面。

## 当前范围

- `/problems`：题库、搜索、难度/标签/个人状态组合筛选、排序、分页、隐藏标签与练习统计。
- `/problem/:id`：题目、公开样例、CodeMirror C++ 编辑器、本机草稿、固定演示运行与提交。
- `/submissions`：全站/本机演示记录、过滤、排序、分页。
- `/submission/:id`：结果、独立代码快照、公开摘要、继续修改与草稿覆盖确认。
- 未找到路由、题目或提交时提供返回入口；数据加载失败提供重试。

后端当前只有 `/api/health`，没有题库、登录或判题接口。所有 OJ 数据均为演示，正式提交和个人中心禁用并解释原因。编辑器只开放 C++17 编辑；Python 和 Java 显示规划中。没有真实执行、编译、隐藏测试或真实账户，也没有按代码或随机数推断评测结果。

## 数据和演示约定

`api.ts` 集中封装读取、草稿、运行和提交，未来可以在这个边界接入真实接口。`problems.ts` 是 8 道演示题的唯一来源。最短路统一为给定起点 `s` 到所有顶点的有向非负权最短路；样例和模板一致。

`DEMO-F…` 为 10 条预置状态快照；其他演示用户的源码不在返回数据中。预置 Pending/Judging 仅展示未完成状态，不代表有后台任务正在评测。

`DEMO-L…` 是用户明确触发的本机演示提交，使用唯一编号和提交时的代码快照。固定场景由界面显式选择：AC、WA、CE、RE、TLE、MLE、系统异常或网络失败。网络失败不创建提交；CE 不展示测试点。刷新中断的模拟提交恢复为明确的系统异常，防止永久停留在等待状态。

运行测试不写入提交记录，不更新练习状态。AC 运行场景展示固定公开样例输出；自定义输入没有匹配公开样例时，不提供预期答案、不判断代码正确。结果、耗时、内存及编译信息都明确标注为模拟数据，编译器版本显示未接入。

通过率来自所有演示记录中 AC 与已完成有效评测的比例，排除 Pending/Judging/系统异常。练习进度仅来自本机演示用户，按题目去重；最近通过统计最近 7 天不同题目的 AC；待复盘为尝试失败且没有 AC 的不同题目。没有真实统计。

演示身份可启用/停用，停用时“我的提交”和个人状态显示登录提示。启用的身份是本机体验偏好，不是身份认证。所有数据保存在当前浏览器，无法跨设备同步。

## 文件

- `../../oj.html`、`../oj.ts`：入口与路由。
- `OjApp.vue`：公共导航接入、演示说明、身份视图切换。
- `ProblemList.vue`、`ProblemDetail.vue`、`SubmissionList.vue`、`SubmissionDetail.vue`：四个业务页面。
- `CodeEditor.vue`：成熟编辑器、字号、换行、模板、重置确认、复制、全屏与键盘操作。
- `Sidebar.vue`、`Pagination.vue`、`StatusBadge.vue`、`NotFound.vue`：共享模块组件。
- `types.ts`、`problems.ts`、`api.ts`、`store.ts`：数据模型、题目、演示访问层和共享状态。
- `../styles/oj.css`：仅针对 OJ 的布局与响应式样式。
- `../../scripts/test-oj.mjs`：隔离的内存数据测试，不读取或覆盖浏览器草稿。
- `../../package.json`、`../../package-lock.json`：CodeMirror 依赖和检查命令。

## 检查

```powershell
npm run test:oj
npm run build
```

数据测试覆盖：样例与模板一致性、运行不生成记录、无预期输出、请求失败、完整状态转换、唯一编号、快照不受草稿覆盖、AC 去重、草稿隔离、源码访问范围、分页、损坏缓存及刷新中断。

手动复核：搜索/筛选后进入题目再返回；第二页返回位置；编辑与刷新恢复；运行固定样例/CE；提交并打开详情；继续修改接受或取消覆盖；网络失败保留代码/输入并重试；未登录视图、无匹配记录、数据加载失败重试、无效题目/提交；桌面与 320px 手机布局、标签页切换、字号/换行/全屏。

编辑器配置参考 [CodeMirror 官方文档](https://codemirror.net/docs/ref/) 与 [动态配置示例](https://codemirror.net/examples/config/)。真实登录、正式评测、编译器版本和权限控制必须由未来后端提供，接入前应重新确认范围。

# 动画与视觉优化

沿用 Vue 3、TypeScript、Vite 多页面入口及 OJ 的独立 hash 路由。没有新增依赖，没有迁移路由或改动后端、题目数据、文章内容、评测接口与演示规则。

## 改动文件

- `src/styles/experience.css`：统一动效时间、颜色、字号、间距、卡片圆角与阴影、触屏反馈、响应式边界、减少动态效果规则。使用明确的 `:root` 作用域，避免生产构建抽取共享 CSS 后被页面样式覆盖。
- `src/main.ts`、`src/code-sharing.ts`、`src/article.ts`、`src/author.ts`、`src/info-page.ts`、`src/oj.ts`：在各入口接入共享体验样式。
- `src/components/Navbar.vue`：菜单进出过渡、Escape、焦点恢复、点击外部关闭、菜单互斥与搜索浮层互斥。
- `src/composables/surfaceTransition.ts`：退出开始时立即设置 inert 和 aria-hidden，防止动画期间的残留内容接收输入。
- `src/components/UiIcon.vue`：复用项目既有 SVG 的绘制方式，统一主要操作图标；不替换 Logo。
- `src/views/CodeSharingView.vue`：搜索浮层过渡、筛选结果短淡入、连续侧栏操作仅执行最后一次位置补偿、复用本地作者头像。
- `src/oj/CodeEditor.vue`、`src/oj/OjApp.vue`、`src/oj/Sidebar.vue`：统一编辑器工具栏、模块导航和推荐区图标。
- `src/oj/OjSkeleton.vue`：静态骨架占位，无人为等待和装饰性循环动画。
- `src/oj/ProblemList.vue`、`src/oj/SubmissionList.vue`：初次加载骨架，刷新与失败时保留已加载的列表并提供提示、重试。
- `src/oj/ProblemDetail.vue`、`src/oj/SubmissionDetail.vue`：初次加载占位，刷新失败保留已有详情；结果淡入、反馈预留空间。

## 交互约定

按钮与标签使用约 140ms，浮层约 180ms（退出 120ms），内容淡入约 180ms，首页入场 360ms。优先使用 opacity / transform；不使用 transition: all、全局入场动画或持续背景动画。

文章筛选直接替换为最终结果，仅做透明度动画，没有退出残影、结果容器高度动画或自动跳转。原有标签取消与侧栏位置补偿保持；快速操作只允许最后一次补偿生效。

OJ 手机标签页通过 CSS 显示与隐藏现有面板，编辑器实例没有重新挂载。骨架只是初次加载的视觉占位，不提供虚构内容或数字。刷新时保留已知数据，失败提示明确说明加载失败。

减少动态效果时，新过渡、淡入和按压移动全部关闭；菜单展开、选中状态和错误信息仍通过静态样式表达。触屏不依赖悬停识别可点击项。

## 验证

- `npm run build`：TypeScript 与生产构建通过。现有 CodeMirror 题目页 chunk 仍有约 537KB 的包体积提示，编辑器继续按路由加载。
- `npm run test:oj`：12 项既有数据检查通过，包括模拟运行与正式记录分离、快照、草稿、异常与权限范围。
- 菜单 / 搜索：打开、Escape、焦点恢复；退出动画期间 inert 生效，隐藏内容不接收点击和键盘焦点。
- 分享：标签再次点击取消、连续筛选以最终条件为准、分类按钮与标签位置补偿。排除测试工具自动聚焦滚动后，分类控件变化小于 1px。
- OJ：手机标签页保留代码、输入和撤销历史，始终只有一个 CodeMirror 实例；样例复制、全屏退出正常。
- 生产预览：网络失败不生成记录且保留草稿；重试提交生成 WA 演示记录，详情显示原始快照，继续修改可恢复；加载失败时保留编辑器 / 列表，重试正常。
- 首页、分享、文章、作者、OJ 题库及题目在 320px、390px 的布局；主要页面在 1280px 的生产布局。内容宽度不超过扣除滚动条后的视口宽度；代码和宽表格内部滚动。
- 文章目录、标题焦点、URL 锚点和阅读进度保持原有实现，未改变阅读计算逻辑。
- 生产版样式核对：标签为统一浅色、卡片圆角 16px、按钮过渡 140ms，与开发版一致。

浏览器当前未启用系统“减少动态效果”，工具只提供尺寸模拟。已检查实际加载的 CSS 中关闭规则的覆盖范围，尚未进行该系统偏好的模式切换实测。没有测量帧率或性能提升百分比，不宣称量化提升。导航栏原有模糊效果保留，没有未经测量就判定其为性能瓶颈。
